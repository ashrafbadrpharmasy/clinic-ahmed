# Clinic Ahmed

Independent clinic website project.

## Current state
- Responsive Arabic landing-page starter.
- No real clinic contact details, services, prices, or working hours have been invented.
- Online booking is intentionally not active until the clinic schedule and Supabase backend are configured.

## Planned setup
- Frontend hosting: Vercel.
- Database and authentication: a dedicated Supabase project for this clinic.
- Admin dashboard for services, prices, working hours, and bookings.
- Appointment conflict protection, including overlapping appointment durations.
- Clinic timezone: Africa/Cairo.

## Before launch
1. Confirm the dedicated Supabase project.
2. Configure secure database policies and booking flow.
3. Add verified clinic details and actual service prices.
4. Add the admin account through Supabase Auth.
5. Test booking conflicts and privacy protections.
6. Connect this repository to Vercel and verify the deployed site.
